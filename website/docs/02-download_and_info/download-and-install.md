# Download & Install

### 1. **Visit** [agelapse.com](https://agelapse.com)
### 2. **Select** your platform:
- **Mobile (iOS & Android)** - Recommended 
- **Desktop (Windows & macOS)** - Beta / Fewer features

:::tip
We recommend using the Mobile app for improved photo alignment, advanced
customization features and app stability. Worried about transferring a large 
quantity of photos from your PC? Simply create a .zip file on your PC, transfer it
to your phone, and import the .zip file directly into AgeLapse.
:::

### 3. **Download** the installer or app package and follow your OS prompts to install.
