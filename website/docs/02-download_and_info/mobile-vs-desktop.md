# Mobile vs. Desktop

While AgeLapse’s desktop version offers full auto-stabilization and basic customization, we strongly recommend using the 
**Mobile App** if you have an iPhone or Android device:

- **Superior Stabilization**  
  - Our mobile app uses improved face detection models (MLKit - designed by Google) and two-pass stabilization. Due to these 
  factors, the mobile app's alignment is superior to the desktop app, at least for now.  

- **Enhanced Features**
    - Built‑in camera capture with live pose guidance
    - Manual stabilization option - for the rare cases where eyes cannot be detected due to obstructions
  such as sunglasses, etc. 
    - In‑app reminders & notifications
    - Direct sharing to social platforms

- **Auto-Update (iOS)**  
  On iOS, the App Store delivers the latest fixes and updates automatically. 

If you prefer desktop, the process is nearly identical, but for the highest‑quality results and advanced features, 
choose the mobile version if possible.
