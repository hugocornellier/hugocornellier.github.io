# Quick Start - Desktop

Here is a quick start guide for the Desktop version of AgeLapse.

## 1. Download and Install
1. Go to `agelapse.com`.
2. Download the Windows or Mac installer for your OS.
3. Run the installer.

### macOS Security Note
If you encounter a macOS warning when opening the app for the first time:
1. Open **System Settings** → **Privacy & Security**.
2. Scroll to **Allow apps downloaded from**.
3. Click **Open Anyway** for AgeLapse.

## 2. Create a New Project
1. Launch **AgeLapse**.
2. Drag & drop your image folder or files into the main window.

## 3. Configure and Stabilize
1. (Optional) Select a custom frame rate / resolution. 
2. Click **Start Stabilization**.
3. Sit back while AgeLapse processes and aligns your photos automatically.

## 4. View Your Video
1. Once stabilization completes, click **Open Video Folder**.
2. Locate and play your stabilized time-lapse video.

> **Note:** The app is 100% free and open source. If AgeLapse helps you, please star the [GitHub repository](https://github.com/hugocornellier/agelapse), and consider leaving a review.
