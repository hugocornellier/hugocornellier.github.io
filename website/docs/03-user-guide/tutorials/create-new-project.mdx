    </div>
    <img
        src="/img/tutorials/create_proj_tut2.png"
        alt="Create Project Step 2"
        class="step-img"

    <div class="step">

    </div>
    <div>
        Select your project type, enter a name, then hit <strong>Create</strong>.
        <ul>
            <li><strong>Face</strong> — For aging/selfie timelapses. Uses eye detection for alignment.</li>
            <li><strong>Pregnancy</strong> — For bump progression photos. Uses body pose detection.</li>
            <li><strong>Body/Muscle</strong> — For fitness transformation photos. Uses body pose detection.</li>
        </ul>
