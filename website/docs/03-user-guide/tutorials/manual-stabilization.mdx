# Manual Stabilization

Use manual stabilization to fine-tune photos that didn't align correctly, or to adjust photos where automatic detection failed.

## When to Use

- Photos showing ⚠ "No Faces Found" status
- Photos showing ✗ "Failed" status
- Photos that aligned but look slightly off
- When you want precise control over positioning

## Step-by-Step Guide

<div className={"tutorial"}>
    <div class="step">
        ## <div class="step-circle">1</div><span class="step-text">Open a photo for adjustment</span>
    </div>
    <div>
        In the <strong>Gallery</strong>, tap on a photo you want to manually adjust. Look for photos with warning badges.
    </div>

    <div class="step">
        ## <div class="step-circle">2</div><span class="step-text">Position the image</span>
    </div>
    <div>
        Use touch or mouse to adjust:
        <ul>
            <li><strong>Drag anywhere</strong> on the image to move it</li>
            <li><strong>Drag corner handles</strong> to resize (maintains aspect ratio)</li>
            <li><strong>Drag edge handles</strong> to stretch</li>
            <li><strong>Drag the rotation handle</strong> (top center) to rotate</li>
        </ul>
        Align your eyes with the guide lines shown on the preview.
    </div>

    <div class="step">
        ## <div class="step-circle">3</div><span class="step-text">Fine-tune with controls</span>
    </div>
    <div>
        For precise adjustments, use the control panel:
        <ul>
            <li><strong>Horiz. Offset</strong> — Shifts image left (negative) or right (positive)</li>
            <li><strong>Vert. Offset</strong> — Shifts image up (negative) or down (positive)</li>
            <li><strong>Scale Factor</strong> — Zoom level (1.0 = original size)</li>
            <li><strong>Rotation</strong> — Tilt in degrees (positive = clockwise)</li>
        </ul>
        Use the +/- buttons for small adjustments, or type values directly.
    </div>

    <div class="step">
        ## <div class="step-circle">4</div><span class="step-text">Save your changes</span>
    </div>
    <div>
        When your eyes align with the guide lines, tap <strong>Save</strong> (top-right). Your changes will be applied to the stabilized output.
    </div>
</div>

## Keyboard Shortcuts (Desktop)

Speed up your workflow with these shortcuts:

### Movement
| Key | Action | With Shift |
|-----|--------|------------|
| ← | Move left 1px | Move left 10px |
| → | Move right 1px | Move right 10px |
| ↑ | Move up 1px | Move up 10px |
| ↓ | Move down 1px | Move down 10px |

### Rotation
| Key | Action | With Shift |
|-----|--------|------------|
| `[` | Rotate counter-clockwise 1° | Rotate 15° |
| `]` | Rotate clockwise 1° | Rotate 15° |

### Scale
| Key | Action | With Shift |
|-----|--------|------------|
| `+` or `=` | Scale up 1% | Scale up 10% |
| `-` | Scale down 1% | Scale down 10% |

### Undo / Redo
| Key | Action |
|-----|--------|
| `Ctrl+Z` (or `Cmd+Z`) | Undo last change |
| `Ctrl+Shift+Z` (or `Cmd+Shift+Z`) | Redo |
| `Ctrl+Y` | Redo (Windows) |

### Reset
| Key | Action |
|-----|--------|
| `Home` | Reset to original position |
| `Ctrl+R` (or `Cmd+R`) | Reset to original position |
| `Ctrl+0` (or `Cmd+0`) | Fit image to canvas |

:::tip
Use **Shift** with movement and rotation keys for larger adjustments. This makes it quick to make big changes, then fine-tune with smaller increments.
:::
