# Quick Start

## Download and Install
1. Go to [agelapse.com](https://agelapse.com)
2. Select the applicable download for your device
3. Install and open the **AgeLapse** app

## Create Your First Project
1. On the first open, you'll be asked to create your first project
2. Enter a project name
3. Tap **Create**

## Import Photos
1. Tap **Import** (top-right in the gallery). Need a walkthrough? Open **Info → Tutorials → Import photos**
2. Select:
- **ZIP archive** _(recommended)_
- **Gallery** or **File System** (AgeLapse supports: `.png`, `.jpg`, `.jpeg`, `.webp`, `.heic`, `.avif`)
3. Wait for the import to finish – photos will be auto-sorted by date

:::tip
For large batches (50+), zip them on your PC first to preserve metadata and speed up import.
:::

:::info
Photos are automatically sorted by date. [Learn how AgeLapse determines photo dates →](../photo-dates)
:::

## Stabilize Your Photos
1. Switch to the **Stabilize** tab
2. Watch your photos align and stabilize in real time
3. Sit back and relax while AgeLapse handles everything automatically

:::info
If using a mobile device, you may have to leave your app open during stabilization. This is due to restrictions imposed by your phone. It'll be worth it, we promise!
:::

## Preview and Customize
1. After stabilization, tap **Play Video** in the bottom navigation bar
2. Adjust playback speed using the **Speed** control
3. Open **Settings** to customize output:
- **Eye Position** (inner eye distance, vertical offset)
- **Frame Rate**
- **Orientation**
- **Resolution**
- **Aspect Ratio**

## Advanced Features
1. **Live Stabilization**: Any photo you take in-app (front/back camera) auto-aligns
2. **Multiple Projects**: Manage several projects side by side
3. **Reminders**: Set project reminders to keep you on track
