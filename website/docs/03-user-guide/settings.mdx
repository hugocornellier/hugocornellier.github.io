# Settings

Customize AgeLapse to match your preferences.

## Theme

Choose your app appearance:

- **System** — Follows your device's light/dark mode setting
- **Light** — Always use light theme
- **Dark** (Default) — Always use dark theme

**How to change:** Settings → Appearance → **Theme**

:::info
System mode automatically switches between light and dark when your device changes modes.
:::

## Settings Overview

The Settings screen is organized into sections:

| Section | What It Contains |
|---------|------------------|
| **Video Settings** | Resolution, aspect ratio, framerate, auto-compile |
| **Eye Position** | Output alignment configuration |
| **Appearance** | Theme and visual preferences |
| **Gallery Settings** | Grid size, date labels |
| **Date Stamp** | Export date stamp configuration |
| **Watermark** | Watermark image and positioning |
| **Reminders** | Daily photo reminder notifications |
| **About** | App version, support, privacy policy |
